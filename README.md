# Administrador de procesos · Gestor de documentos (UMG)

Proyecto del curso **Autómatas y Lenguajes Formales**, Universidad Mariano Gálvez de Guatemala.

Cada documento avanza por los estados de un **autómata finito determinista** M = (Q, Σ, δ, q0, F): solo se permiten las transiciones definidas en δ.

**Sitio:** https://www.cosasperdidas.shop

- Panel, tablero (kanban) controlado por δ, registro de documentos con archivo adjunto, detalle con historial, vista del autómata (tabla δ, grafo con Graphviz, lienzo de arrastrar y soltar, probador de cadenas) y estadísticas.
- Funciona sin servidor: los datos y archivos se guardan en el navegador de cada persona.
- Para usarlo sin internet, descarga el repositorio y abre `index.html`.
